# AI Agent Engineering Fundamentals

A Docusaurus field guide to the AI-assisted software engineering fundamentals covered in Matt Pocock's workshop, **Full Walkthrough: Workflow for AI Coding**.

## Local development

```bash
npm install
npm run start
```

## Production build

```bash
npm run build
npm run serve
```

## Deployment

The workflow in `.github/workflows/deploy-pages.yml` builds pull requests and deploys `master` to GitHub Pages.

- Site: `https://stegeler.github.io/PlatformCoding101/`
- Node.js: 22
- Docusaurus: 3.10.2

## Content structure

1. Model mechanics
2. Agent configuration
3. Intent and planning
4. Work decomposition
5. Agent execution
6. Quality control
7. Architecture
8. Knowledge lifecycle
9. End-to-end workflow
